The road graph, route, transformed building footprints, inferred building
attributes, landuse and geographic chunk database are a modified/derivative
OpenStreetMap database distributed under ODbL 1.0. This database is NOT covered
by the project's CC0 declaration for original procedural artwork.

The cached source snapshot is source.osm.json.gz (gzip JSON); its SHA-256,
retrieval date and exact four API export URLs are in attribution.json.
The deterministic modification pipeline is tools/import-pune.mjs and tools/lib/.
The source snapshot and modified database are offered with the deployed site.
Original non-geographic procedural cabin/vegetation/facade artwork remains
separately documented in ASSETS.md. No Google-derived data is used.
